# Protocolos de pruebas – EVI

App para generar protocolos de pruebas de transformadores (PDF, Excel y formato de campo).

Abrir: https://luisangel12569-stack.github.io/protocolos-evi/

Funciona sin instalar nada. Los datos se guardan en el navegador de cada equipo; para pasarlos entre equipos usa 📁 Protocolos → Exportar todo (.json) e Importar .json.
